## Целевая модель

1. **Шестерёнка ⚙** — в строке вкладок справа: `Конспект · Транскрипт · Чат · ● ⚙`
   (● — индикатор автосохранения, переезжает сюда из угла текстовой области;
   состояние сохранения поднять из `VideoStudyNotesPanel` на уровень оверлея).
   В шестерёнке:
   - «Таймкоды в конспекте» вкл/выкл (тумблер уходит из панели);
   - «Мои вопросы видят»: группа и лекторы / только лекторы;
   - «Мой конспект видят»: только я / группа и лекторы / только лекторы.
2. **Область действия настроек видимости**: настройка в оверлее действует на
   ТЕКУЩУЮ лекцию; на странице профиля — дефолты аккаунта; приоритет у
   per-lecture. **Дефолты для всех: вопросы — «группа и лекторы», конспект —
   «только я»** (приватный).
3. **Вкладка «Вопросы» → «Чат»**: единая лента по таймкодам лекции — вопросы
   одногруппников + абзацы их ОТКРЫТЫХ конспектов + свои записи (свои помечены
   «Вы»; без своих записей диалог рвётся). Клик по таймкоду — перемотка.
   Компактный чип-фильтр «только вопросы» в одну строку.
4. **Лектор** (canEditCourse) видит в чате ВСЕ вопросы лекции (не только своей
   группы) и только открытые конспекты.
5. **«?» на абзаце конспекта** — главный способ задать вопрос: маленькая кнопка
   справа от абзаца (всегда видна у активного абзаца, у остальных — на hover;
   у отправленного горит постоянно). Пометка создаёт вопрос-СНАПШОТ в
   `lectureQuestions` (текст абзаца + его startMs, аудитория — из настройки
   «мои вопросы видят»). Редактирование абзаца после отправки вопрос НЕ обновляет.
   Снятие «?» удаляет свой вопрос. **НЕ двойной клик** (конфликт с выделением
   слова, случайные отправки) — обсуждено и отклонено.
6. **Живой открытый конспект**: конспект либо приватный, либо открыт (правки
   видны сразу). Ручной «Поделиться конспектом» и `ShareLectureNoteModal`
   выпиливаются; коллекция `sharedLectureNotes` — легаси, старые записи не
   показываем (их почти нет), миграция не нужна.
7. **Плотность конспекта**: убрать min-h у сегментов-textarea и большие пустоты;
   обычный межстрочный интервал, композер сразу под последним абзацем.
   Конспект читается как сплошной текст.

## Схемы интерфейса (утверждены)

Вкладка «Конспект» (таймкоды вкл; «?» у активного абзаца):

```
│  Конспект   Транскрипт   Чат      ● ⚙  │
├─────────────────────────────────────────┤
│ 00:12  Аффект — это не то же самое,     │
│        что эмоция, потому что…          │
│ 04:31  Не понял про дисрегуляцию    [?] │  ← помечен: ушёл как вопрос
│ 07:02  Зейгарник: патопсихология…     ? │  ← «?» на hover/фокусе
│ Пишите конспект по ходу лекции…         │
```

Вкладка «Чат»:

```
│  Конспект   Транскрипт   Чат      ● ⚙  │
├─────────────────────────────────────────┤
│                      [ ? только вопросы]│
│ 00:12 · Маша                        [?] │
│   А чем аффект отличается от эмоции?    │
│ 00:15 · Вы                              │
│   Аффект — это не то же самое, что…     │
│ 04:31 · Пётр · конспект                 │
│   Дисрегуляция — когда система…         │
```

Шестерёнка — поповер с тремя настройками (см. выше).

## Этапы

### Этап A — чистый UI, без новых данных
- Плотность редактора конспекта (интервалы, композер под текстом).
- Индикатор автосейва + шестерёнка в строку вкладок (внутри пока только «Таймкоды»).
- «Вопросы» → «Чат» (переименование вкладки), чип-фильтр «только вопросы»
  (фильтрует уже существующую ленту вопросы+shared).

### Этап B — «?» на абзаце
- Кнопка «?» у абзаца → вопрос в существующую `lectureQuestions` (снапшот;
  снятие — удаление своего вопроса; связь абзац↔вопрос хранить, напр.
  `sourceSegmentId` в вопросе или `questionId` в сегменте — решить при реализации).
- Настройка «мои вопросы видят» в шестерёнке (per-lecture; хранение —
  рекомендация: localStorage по lectureKey) + дефолт аккаунта на странице
  профиля (поле в `users/{uid}`, напр. `studyDefaults.questionsVisibility`).
- Убрать «Спросить лектора»-модалку из оверлея (на странице занятия секция
  «Вопросы к семинару» пока остаётся как есть).

### Этап C — живой открытый конспект (самый чувствительный этап)
- Поле видимости в lecture-заметке (напр. `visibility: 'private'|'group'|'lecturers'`,
  дефолт private) + ДЕНОРМАЛИЗАЦИЯ групп автора в заметку (`groupIds` снапшотом
  при открытии доступа) — без этого запрос «заметки одногруппников» не построить.
  Паттерн — как в `lectureQuestions`.
- Firestore rules: чтение чужих notes ТОЛЬКО lecture-scope и ТОЛЬКО с явной
  видимостью; manual/timeline-заметки никогда не открываются. Обязательны
  rules-тесты в `tests/integration/firestoreRules.test.ts` ДО деплоя rules.
  Деплой rules — только после явного одобрения Алексея (CLAUDE.md).
- Чат: абзацы открытых конспектов одногруппников по таймкодам; лекторский
  режим (все вопросы курса-лекции + открытые конспекты).
- Настройка «мой конспект видят» в шестерёнке (пишется в саму заметку) +
  дефолт в профиле.
- Выпил share-контура: кнопка, `ShareLectureNoteModal`, событие телеметрии
  `note_shared` (убрать из словаря или пометить legacy), отображение
  `sharedLectureNotes` из чата и `LessonQuestionsSection`.
- Учесть бэклог LP-17 (fan-out листенеров): не плодить лишние подписки.
