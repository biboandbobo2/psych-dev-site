# Макет редизайна DOM Academy (дизайнер — Дарья Гапоненко)

Кликабельный HTML-макет публичной части и админки. Это не код сайта: здесь только материалы для переноса в React.

## Как открыть

- Скачайте папку `макет-сайта/` и откройте `index.html` в браузере. Нужен интернет (шрифт Manrope с Google Fonts).
- Сверху — вкладки экранов и переключатель роли («студент / со-админ / админ / суперадмин»). Пунктирные полоски — состояния, которые есть только в макете (загрузка, ошибка, пусто и т. п.).
- Подсказки внизу экрана (тосты) называют настоящий адрес страницы на сайте там, где экран в макете не нарисован.

| Файл | Что это |
|---|---|
