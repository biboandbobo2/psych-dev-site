# Что поменять в коде сайта по макету

Этот список — для разработчика, который будет переносить макет в React. Его же нужно целиком вставить в описание пулл-реквеста.

В каждом пункте указано, что нарисовано в макете и что для этого нужно поменять в коде. Пометки:

- **[вернуть]** — функция уже есть в коде, в макете её потеряли, теперь нарисовали заново. Нужно перенести её в новый дизайн, не потеряв поведение.
- **[изменить]** — макет меняет поведение. Нужна правка логики.
- **[данные]** — нужны новые поля, правила Firestore, функции или админка.
- **[решение]** — изменение, которое должен утвердить тимлид.

Номера строк даны по коммиту `f29a67f`. **Сверка со свежим `main` (3ae849fb, 08.10.2026) — в `сверка-с-main.md`:** по каждому пункту указано, сделан ли он уже, частично, не сделан (с новыми путями) или устарел. Главное: гостевая главная переписана, админка получила права админа курса и кабинет автора, режим конспекта — вкладку «Чат», учёт просмотра идёт по каждому видео с порогом 60% (в макете — 80%), кода «Достижений» нет.

  - На телефоне то же меню открывается нижней шторкой, как «Меню» в `UserMenu.tsx:223-333`.
- **[изменить] «Обратная связь» видна всем ролям**, в том числе админам. Сейчас на десктопе она скрыта у admin и super-admin (`!isAdmin`).

## Куда ведут кнопки: сверка макета с сайтом (05.10)

Все кнопки и ссылки макета сверены с кодом сайта (HEAD). Где на сайте есть такая же кнопка, макет ведёт туда же. В тостах-заглушках указан настоящий адрес (`/booking`, `/timeline`, `/disorder-table`, `/tests/dynamic/<id>`, `/admin/content…`, `/superadmin/pages/about`, `/warm_springs2`, `/vozrast`).

Намеренные отличия макета, ждут тимлида или уже описаны выше:
- поиск и AI — страницы, а не панели;
- тесты — одна страница с вкладками «По занятиям / По курсу» вместо `/tests-lesson` и `/tests`;
- вход — страница;
- меню пользователя по аватару;
- профиль с разделами;
- «Достижения»;
- хлебные крошки и «предыдущее / следующее» на занятии;
- кнопка входа на заглушке видео.

Ссылки макета, которым на сайте нужен адрес:
- «Подключить в профиле» (AI) и «Вся история →» (поиск) ведут в разделы профиля. **[изменить]** Дать секциям профиля якоря `#gemini-key` и `#search-history`, ссылки — `/profile#gemini-key`, `/profile#search-history`.
- «Повторить поиск» в истории открывает поиск с этим запросом — как `openSearch(entry.query)` на сайте.
- Таймкоды из поиска и AI открывают занятие на вкладке «Транскрипт» (`?panel=transcript&study=1&t=…`), таймкоды из конспектов — на вкладке конспекта (`panel=notes`).

**Ошибки на самом сайте, найденные при сверке:**
- `Login.tsx:12` — после входа без `from` уводит на `/admin`, студент видит «Access denied». Нужно `/home` и нейтральный текст страницы.
- `NotFound.jsx:29` — «На главную» ведёт на `/prenatal`. Нужно `/home`.
- `DynamicTest.tsx:83,104,177` — «Вернуться к тестам» и редирект после ошибки всегда на `/tests`, даже для тестов по занятиям. Нужно `/tests-lesson` для них.
- `pages/home/homeHelpers.ts:26-30` — «Продолжить» у динамического курса без истории ведёт на `/profile?course=<id>`. Нужно первое занятие курса.
