# Как сейчас устроена админка курсов

Снято с кода сайта (коммит `HEAD f29a67f`) 05.10.2026. Нужна, чтобы понимать, где админ меняет содержание курса, и если дойдём до редизайна админки.

## Коротко

- **Содержание курса** правится в разделе «Управление контентом» (`/admin/content`). Туда ведёт кнопка «Редактор» в шапке — её видят админ и суперадмин.
- **Занятие** (видео, понятия, персоналии, литература, досуг, самопроверка) правится одной длинной формой на `/admin/content/edit/<id занятия>`.
- **«Книжки» в занятии** — это списки «Основная литература» и «Дополнительная литература» в форме занятия: название и ссылка, до 10 пунктов.
- **«Библиотека книг»** (`/admin/books`) — другое: это PDF для AI-поиска «по книгам». Вход только из админ-панели суперадмина.

## Как попасть

| Откуда | Кнопка | Куда | Кто видит |
|---|---|---|---|
| Шапка | «Редактор» | `/admin/content?course=…` (курс берётся из текущей страницы) | админ, суперадмин |
| Шапка | «Админ-панель» | `/superadmin` | суперадмин |
| Шапка | «Со-админ» | `/coadmin` | со-админ |

Отдельной страницы с плитками у админа нет: `/admin` просто перенаправляет — суперадмина в `/superadmin`, остальных в `/admin/content`.

## «Управление контентом» — `/admin/content`

- **Слева — список курсов:**
  - «Добавить курс» — окно «Создать новый курс»: название, ID, список занятий;
  - карандаш у курса — «Редактировать курс»: название, иконка, «Курс виден студентам», «Удалить курс»;
  - ниже «Навигация курса» — клик открывает занятие так, как его видит студент, а не редактор.
- **Шапка раздела:** «Вопросы студентов», «О курсе», «Кабинет объявлений».
- **Кнопки:** «Добавить занятие» — создаёт черновик и сразу открывает редактор; «Создать тест» — окно управления тестами; «Темы заметок».
- **Список занятий:** перетаскивание меняет порядок, метки «Опубликовано» / «Черновик». Клик открывает редактор занятия. Публикация включается галочкой внутри редактора, а не в списке.

## Редактор занятия — `/admin/content/edit/<id>`

Одна длинная форма, сохраняется одной кнопкой «Сохранить изменения». Черновика нет; после сохранения появляется системное окно «Изменения сохранены!».

1. **«Основная информация»:** название, подзаголовок, порядок, «Опубликовано (видно студентам)», «Показывать заглушку «Скоро обновление»».
2. **«Цвета темы»:** два цвета.
3. **«Видео-лекция»** — плейлист видео. У каждого видео: название, ссылка на видео, на презентацию, на аудио и галочка «виден без оплаты».
4. **«Понятия»** — название и ссылка.
5. **«Ключевые авторы»** — у студентов называется «Персоналии».
6. **«Основная литература»**, **«Дополнительная литература»** — название и ссылка, до 10 пунктов.
7. **«Дополнительные видео»**.
8. **«Досуговое»** — название, ссылка, тип, год.
9. **«Вопросы для самопроверки»** — ссылка на рабочую тетрадь.

Внизу кнопки «Назад», «Удалить период», «Сохранить изменения».

## Другие разделы

- **«О курсе»** — `/admin/content/course-intro/<id курса>`: «Ключевые факты», «Идея курса», «Программа», «Авторы курса», «Кнопка записи». Для идеи и программы есть AI-черновик. Вход — кнопка «О курсе» в «Управлении контентом».
- **Тесты** — только через «Создать тест» в «Управлении контентом» (окно «Управление тестами»: список, создание, импорт и экспорт JSON).
- **Темы заметок** — `/admin/topics`.
- **Объявления** — `/admin/announcements`, кнопка «Кабинет объявлений».
- **Вопросы студентов** — `/admin/questions`.
- **Только из «Админ-панели»** (`/superadmin`, вход у суперадмина):
  - «Users» — пользователи, админы, со-админы, массовое открытие курсов;
  - «Архив функций»;
  - «Группы»;
  - «Books» — библиотека PDF для AI;
  - «Страницы» — «Об Академии» и страницы проектов;
  - «Экзамены»;
  - «Телеметрия»;
  - слева «Роли и задачи».
- **«Со-админ»** (`/coadmin`) — одна плитка «Страницы».

## Кто что может

- Суперадмин — всё.
- Обычный админ правит только курсы, отмеченные у него в «Редактируемые курсы». Для чужого курса кнопки неактивны, с подсказкой «Нет прав на редактирование этого курса».
- Со-админ правит только «Страницы» («Об Академии», проекты).
- «Группы», «Экзамены», «Телеметрия» — только суперадмин.

## Что бросается в глаза (на будущее)

- Нет единой «главной» админки: у суперадмина «Админ-панель» без ссылки на «Управление контентом», у админа — только кнопка «Редактор».
- «Библиотека книг» и «Пользователи» доступны любому админу по прямой ссылке, но кнопки на них есть только у суперадмина.
- Редактор занятия — одна длинная форма без черновика. Сохранение одной кнопкой через системное окно `alert`.
- В коде лежат неподключённые редакторы: `AdminHomePage.tsx` (JSON главной) и `ContentEditor.tsx`.

## Подробная карта кликов (06.10.2026, сверено по коду HEAD)

Поправки к тексту выше: «Редактировать курс» — не окно, а форма прямо в строке курса слева; «Темы заметок» — отдельная страница `/admin/topics`, не окно.

### «Управление контентом» `/admin/content?course=<курс>`
- Вход: «✏️ Редактор» в шапке (админ, суперадмин). Курс — с текущей страницы (`/clinical…` → clinical, `/general…` → general, `/course/<id>…` → id), иначе последний выбранный, иначе development.
- **Слева, карточка 1:** «РЕДАКТОР» / «Курсы» / «Выберите курс для редактуры материалов.» / «➕ Добавить курс»; список курсов (иконка, ✏️, название; метка «Скрыт»). Сначала 3 основных, потом созданные.
  - клик по названию → этот курс справа;
  - ✏️ → форма в строке: иконка (сетка 40 эмодзи), «Название курса», «Курс виден студентам» (не у основных), «Удалить курс» (не у основных, confirm «Удалить курс «…» и все его занятия? Это действие необратимо.»), «Отмена» / «Сохранить».
- **Слева, карточка 2:** «НАВИГАЦИЯ КУРСА» — занятия курса, метка «Черновик»; клик открывает занятие глазами студента (не редактор).
- **Справа сверху:** «Управление контентом» и кнопки «❓ Вопросы студентов» → `/admin/questions?course=`, «✨ О курсе» → `/admin/content/course-intro/<курс>`, «📢 Кабинет объявлений» → `/admin/announcements`.
- **Тулбар:** «➕ Добавить занятие» (окно), «📝 Создать тест» (окно «Управление тестами»), «📚 Темы заметок» → `/admin/topics`; слева мигает «Сохранение порядка...».
- **Список занятий:** ⋮⋮, цветная полоска, название, «Опубликовано»/«Черновик», подзаголовок, «ID: … Порядок: …», ✏️. Перетаскивание сразу сохраняет порядок. Клик → редактор занятия. Внизу «💡 Совет: Перетащите период, чтобы изменить порядок…».
- Нет прав на курс (обычный админ): «О курсе», «Добавить занятие», карточки и ✏️ серые, подсказка «Нет прав на редактирование этого курса»; «Вопросы студентов» скрыты.
- **Окно «Создать занятие»:** «Курс» (кнопки-выбор), «Название занятия *», «ID (для URL)» (транслит, «URL: …», «ID уже существует»), плашка «занятие будет создано как черновик с заглушкой…», «Отмена» / «Создать занятие» → сразу редактор занятия.
- **Окно «Создать новый курс»:** «Название курса *», «ID курса», «Занятия курса *» (карточки «Занятие N»: название + ID, «＋ Добавить ещё занятие»), «Отмена» / «Создать курс».
- **Окно «Управление тестами»:** список тестов курса — «➕ Создать новый тест», 📥 импорт JSON, 📄 шаблон, «Фильтры» (поиск, статус, рубрика, число вопросов, сортировка); карточки (эмодзи, название, «Рубрика», «Вопросов», «Следующий уровень после», ID, 🗑️; статус только цветом). Клик → редактор теста в том же окне: «Параметры теста» (название до 20 символов, 1–20 вопросов, курс, рубрика) → доступ после другого теста (порог %) → «Оформление теста» (эмодзи, описание, тема-цвета, бейдж уровня, особенности) → «Вопросы (N)» (сворачиваемые; текст, медиа, варианты с правильным, показ ответа, сообщения, материалы) → «Отмена» / «Сохранить черновик» / «Опубликовать» / «Снять с публикации».

### Редактор занятия `/admin/content/edit/<id>?course=`
Шапка: «←», «Редактирование: <название>», «ID: …». Одна форма, все секции раскрыты:
1. «📋 Основная информация» — «Название *», «Подзаголовок», «Порядок отображения», «Опубликовано (видно студентам)», «Показывать заглушку «Скоро обновление»».
2. «🎨 Цвета темы» — accent, accent100, образец.
3. «🎥 Видео-лекция» — «Плейлист видео», «+ Добавить видео»; карточка «Видео N»: «👁» (видно без оплаты), «Название», «Ссылка на видео *», «Ссылка на презентацию», «Ссылка на аудио», «Предпросмотр», «🗑️ Удалить».
4. «💡 Понятия», 5. «👤 Ключевые авторы», 6. «📚 Основная литература», 7. «📖 Дополнительная литература», 8. «🎬 Дополнительные видео» — списки «название + ссылка», «+ Добавить», 🗑️, до 10.
9. «🎲 Досуговое» — название, ссылка, тип, год.
10. «✏️ Вопросы для самопроверки» — ссылка, «🔗 Открыть материал».
Низ: «← Назад», «🗑️ Удалить период» (confirm), «💾 Сохранить изменения» → alert «✅ Изменения сохранены!» и возврат в список.

### «О курсе» `/admin/content/course-intro/<курс>`
«← К управлению контентом», «<иконка> «О курсе»: <курс>», подсказка про markdown. Секции: «Ключевые факты» (подпись — значение, «+ Добавить факт»), «Идея курса» (текст, «🤖 AI-черновик», «Предпросмотр»), «Программа» (то же), «Авторы курса» («Заголовок секции»; карточки «Автор N» с ↑ ↓, имя, роль, фото — загрузить / URL, биография, ссылки), «Кнопка записи» (текст, ссылка, подпись). Низ: «Есть несохранённые изменения» / «Без изменений», «Отменить», «Сохранить».

### «Темы заметок» `/admin/topics`
Крошка «Редактор → Темы для заметок»; «📚 Управление темами для размышлений»; выбор возрастного периода; «Текущие темы (N)» с «🗑️ Удалить»; «➕ Добавить новые темы» — вставить вопросы по строке, превью, «➕ Добавить темы (N)» / «Очистить».
