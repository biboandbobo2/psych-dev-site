## Состав публикации

Firebase CLI read-only `functions:list` показал 37 существующих функций;
следующих шести функций ещё нет. Планируется **добавить**:

1. `getZoomAttendance` — отчёт группы для назначенного админа.
2. `setZoomAttendanceConnection` — подключение Zoom к группе владельцем.
3. `syncZoomAttendance` — ручной повтор импорта с ограничением частоты.
4. `matchZoomAttendanceParticipant` — привязка участника к студенту группы.
5. `getMyZoomAttendance` — только собственный результат участника группы.
6. `pollZoomAttendance` — автоматический опрос каждые 30 минут.

Изменение/удаление существующих Functions: **0**. Все новые функции —
`us-central1`, runtime Node.js 22, appspot service account.

Правила Firestore: один новый явный рекурсивный запрет для
`zoomAttendanceGroups/{document=**}`. Клиент читает отчёты через callable;
новые публичные read/write права не добавляются. Индексы и Storage rules в
публикацию не входят.

Frontend: панель посещаемости выбранной группы в `/admin/announcements` и
личный результат в карточке события `/home`. Для Vercel нужен отдельный
коммит изменений Zoom и push в `main`; это публикует интерфейс. `main` и
`origin/main` перед подготовкой совпадали на `7afdfb100a218f30da3038ebba99ae804d81604c`.
Уже существовавшие локальные строки QA-журнала нужно сохранить отдельно от
составляемого коммита; чужих runtime-правок в исходном status задачи не было.
