# Учебный ролик «От трёх до семи» (Дошкольный возраст, 3–7 лет)

Третий эпизод серии «Психология развития» DOM Academy: 4:50 для раздела «Дошкольный возраст (3–7 лет)». Третья версия — по двум раундам правок автора (4:40 → 5:02 → 4:50). Как и первые два, ролик без диктора — текст на экране, схемы и оригинальная музыка. Разбор перед эпизодом, сценарий и источники — в [SCRIPT.md](SCRIPT.md).

Ролик собран на [HyperFrames](https://github.com/heygen-com/hyperframes): HTML-страница, которую Chrome покадрово снимает в MP4. Вся анимация — один детерминированный таймлайн GSAP.

## Что нового в этом эпизоде

- **Рисованный слой** — «смысловое поле» Л. С. Выготского: графитовая и оранжевая линия поверх геометрии (`assets/js/sketch.js`, слой `#sketch` над персонажами).
- **Сверстники** `kid2`, `kid3` и второй взрослый `adult2` в движке.
- **Двойной словарь** — международные термины под русскими (`.term > .en`).
- **Акцент для текста** `accentText` (`#A65300`): у оранжевого раздела `#FB8C00` на бумаге контраст 2,2 : 1.
- **«Паспорт» из семи строк**, фамилии — одной колонкой справа (строку «Ключевые исследования» пробовали и убрали).
- **Сцена «Проверку выдерживает не всё»** — знаменитые опыты и что показали повторения.
- **Игрушки и рисованные значки** — `assets/js/toys.js`: мишка, кубики, мяч, ранец, шкафы; лошадка, облако мысли, шоколадка, конфета, ракета, чемоданчик, школа, мозг. Один и тот же значок — в сцене и в финале.
- **Карточка «Приходите на курс»** — QR-коды курса и телеграм-канала (`make_qr.py` → `assets/js/qr.js`); последняя сцена с `hold: true` не растворяется.

## Структура

```
index.html               корневая композиция (290 с), @font-face и FILM_CONFIG эпизода
assets/css/theme.css     дизайн-система серии + акцент эпизода и стили 3–7
assets/js/lib.js         движок серии (+ accentText, сверстники, рисованный слой)
assets/js/sketch.js      рисованный слой: «карандашная» линия (с заливкой)
assets/js/toys.js        игрушки (видимое поле) и рисованные значки (смысловое поле)
assets/js/qr.js          данные QR-кодов финальной карточки (генерирует make_qr.py)
assets/js/scenes-0.js    пролог (палочка → лошадь), титр с картой курса, «сроки — это статистика»
assets/js/scenes-1.js    часть 1 «Как взрослые» — игра
assets/js/scenes-2.js    часть 2 «Мир глазами другого» — мышление
assets/js/scenes-3.js    часть 3 «„Хочу“ против „надо“» — самоконтроль и мораль
assets/js/scenes-4.js    часть 4 «На пороге школы», «паспорт возраста», финал, «Приходите на курс»
music/compose.py         партитура по сценам (свой грув и тональность у глав, тема серии) → preschool.mid
make_qr.py               QR-коды курса и телеграм-канала → assets/js/qr.js
render.sh                полная пересборка: музыка → видео → сведение
```

Длительность сцены задаётся в тактах (`bars`), один такт = 2,5 с. Партитура в `music/compose.py` собрана по тем же сценам: меняя длину или порядок сцен, поменяйте блок сцены в `SCENES`. Акценты челесты — в секундах от начала сцены.

Персонажи живут вне сцен: персонажа, который больше не нужен, гасите явно (`s.actor('kid2', { o: 0 }, …)`), иначе он «протечёт» в следующую сцену.

Персонажа, погашенного в прошлой сцене, включайте явно: `s.actor('baby', { …, o: 0 }, 0, 0.01)` и затем `{ o: 1 }` — иначе он двигается невидимым.

Появление через `s.tween(e, t, { opacity: 0 }, …)`: если это первый твин прозрачности элемента, движок прячет элемент с начала сцены (иначе он виден до своего появления). Анимации персонажа (`s.actor`) не накладывайте по времени друг на друга — каждая задаёт и x, и y; для подпрыгиваний на ходу — `s.squash`, для групп рисунка — `Film.ride`.

## Как пересобрать

Нужны Node 22+, FFmpeg, FluidSynth, банк звуков MuseScore General и Python 3 с `mido` (установка на Linux и macOS — в [`../README.md`](../README.md)).

```bash
./render.sh            # результат: renders/preschool-three-to-seven.mp4 (+ renders/poster.png)
```

Предпросмотр кадров: `npx hyperframes@0.8.78 snapshot . --at 10,60,150`.
