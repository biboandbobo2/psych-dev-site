# Учебный ролик «От трёх до семи» (Дошкольный возраст, 3–7 лет)

Третий эпизод серии «Психология развития» DOM Academy: 4:40 для раздела «Дошкольный возраст (3–7 лет)». Как и первые два, ролик без диктора — текст на экране, схемы и оригинальная музыка. Разбор перед эпизодом, сценарий и источники — в [SCRIPT.md](SCRIPT.md).

Ролик собран на [HyperFrames](https://github.com/heygen-com/hyperframes): HTML-страница, которую Chrome покадрово снимает в MP4. Вся анимация — один детерминированный таймлайн GSAP.

## Что нового в этом эпизоде

- **Рисованный слой** — «смысловое поле» Л. С. Выготского: графитовая и оранжевая линия поверх геометрии (`assets/js/sketch.js`, слой `#sketch` над персонажами).
- **Сверстники** `kid2`, `kid3` и второй взрослый `adult2` в движке.
- **Двойной словарь** — международные термины под русскими (`.term > .en`).
- **Акцент для текста** `accentText` (`#A65300`): у оранжевого раздела `#FB8C00` на бумаге контраст 2,2 : 1.
- **Восьмая строка «паспорта»** — «Ключевые исследования».
- **Сцена «Проверку выдерживает не всё»** — знаменитые опыты и что показали повторения.

## Структура

```
index.html               корневая композиция (280 с), @font-face и FILM_CONFIG эпизода
assets/css/theme.css     дизайн-система серии + акцент эпизода и стили 3–7
assets/js/lib.js         движок серии (+ accentText, сверстники, рисованный слой)
assets/js/sketch.js      рисованный слой: «карандашная» линия
assets/js/scenes-0.js    пролог (палочка → лошадь), титр с картой курса, «сроки — это статистика»
assets/js/scenes-1.js    часть 1 «Как взрослые» — игра
assets/js/scenes-2.js    часть 2 «Мир глазами другого» — мышление
assets/js/scenes-3.js    часть 3 «Хочу, но надо» — воля и правила
assets/js/scenes-4.js    часть 4 «На пороге школы», «паспорт возраста», финал
music/compose.py         партитура по сценам (6/8, ре мажор, тема серии) → preschool.mid
render.sh                полная пересборка: музыка → видео → сведение
```

Длительность сцены задаётся в тактах (`bars`), один такт = 2,5 с. Партитура в `music/compose.py` собрана по тем же сценам: меняя длину или порядок сцен, поменяйте блок сцены в `SCENES`. Акценты челесты — в секундах от начала сцены.

Персонажи живут вне сцен: персонажа, который больше не нужен, гасите явно (`s.actor('kid2', { o: 0 }, …)`), иначе он «протечёт» в следующую сцену.

## Как пересобрать

Нужны Node 22+, FFmpeg, FluidSynth, банк звуков MuseScore General и Python 3 с `mido` (установка на Linux и macOS — в [`../README.md`](../README.md)).

```bash
./render.sh            # результат: renders/preschool-three-to-seven.mp4 (+ renders/poster.png)
```

Предпросмотр кадров: `npx hyperframes@0.8.78 snapshot . --at 10,60,150`.
