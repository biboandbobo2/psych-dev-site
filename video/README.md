# Учебные ролики серии «Психология развития» (DOM Academy)

Короткие (около 3 минут) ролики к разделам курса — без диктора: текст на экране, схемы и оригинальная музыка. Каждый ролик — отдельный проект [HyperFrames](https://github.com/heygen-com/hyperframes), то есть HTML-страница, которая покадрово снимается в MP4.

| Эпизод | Раздел сайта | Папка | Длительность |
|---|---|---|---|
| «Первый год жизни» | Младенчество (0–1 год), `/0-1` | [`infancy/`](infancy) | 3:10 |
| «От года до трёх» | Раннее детство (1–3 года), `/1-3` | [`toddler/`](toddler) | 4:25 |

## Что делает ролики серией

**Общее:**
- знак DOM Academy ([`_brand/`](_brand));
- шрифты сайта;
- герои-геометрия: ребёнок, взрослый, предмет, чужой;
- шкала возраста, заставки глав, маркер;
- музыкальная сетка «такт = 2,5 с» и тема серии.

**Начиная со второго эпизода:**
- **карта курса** в титре и анонс следующего периода в финале;
- **«паспорт возраста»** — итоговая таблица.

**Своё у каждого эпизода:**
- цвет раздела сайта (`src/theme/periods.ts`);
- размер и тональность музыки;
- визуальный мотив.

Как собрать следующий эпизод — в [`toddler/README.md`](toddler/README.md).

## Как продолжить работу в новой сессии Claude Code

Этот раздел — «передача дел»: всё, что нужно новой сессии (облачной или на своём компьютере), чтобы продолжить серию без старого диалога.

**Где лежит.** Ветка `claude/brave-bardeen-iuqek9`: эпизоды `infancy/` и `toddler/`, знак `_brand/`. В `main` она пока не влита. Готовые MP4 в git не хранятся (`renders/` в `.gitignore`); `./render.sh` в папке эпизода пересобирает всё за 5–10 минут.

**Что установить:**

```bash
sudo apt-get install -y ffmpeg fluidsynth musescore-general-soundfont   # macOS: brew install ffmpeg fluid-synth + SOUNDFONT=путь/к/MuseScore_General.sf3
pip install mido
# Node 22+; HyperFrames ставится сам через npx (hyperframes@0.8.78)
```

**В облачной сессии Claude Code:**
- Эти команды удобно добавить в Setup script окружения: меню окружения в заголовке сессии → Edit. Тогда они выполняются при старте каждой сессии.
- Для рендера нужны переменные:
  - `NODE_USE_ENV_PROXY=1` — чтобы npx ходил через прокси окружения;
  - `PRODUCER_HEADLESS_SHELL_PATH` — путь к предустановленному Chromium, например `/opt/pw-browsers/chromium_headless_shell-*/chrome-linux/headless_shell`.

**Проверка:**
- `npx hyperframes@0.8.78 lint .` — ошибки композиции;
- `npx hyperframes@0.8.78 snapshot . --at 10,60` — кадры для просмотра;
- `python3 music/compose.py` — должно печатать `clashes: 0`.

**Договорённости с автором курса:**
- Без диктора: текст на экране, схемы, оригинальная музыка; академичная и простая интонация, без «ИИ-слопа».
- Каркас возраста, а не пересказ лекции. Лекция курса звучит один раз — цитатой в финале.
- Без исторических экскурсов в духе «как менялись взгляды». Формула: «классик выделял…» → «сейчас понимают так…» → «поэтому влияет на развитие так…».
- В начале — кадр «сроки — это статистика». Возрасты везде — средние значения и диапазоны.
- Опора — классика (Выготский, Эльконин, Пиаже, Эриксон, Фрейд) и западные исследования, в том числе последних 25 лет. Автор и год — прямо в кадре, источники — в `SCRIPT.md`.
- Факты проверять. Спорное или невоспроизводимое не брать, как «брокколи» Repacholi & Gopnik.
- Элементы серии:
  - знак DOM Academy;
  - цвет раздела сайта (`src/theme/periods.ts`);
  - карта курса из 14 периодов (взрослость: 27–35, 35–45, 45–65);
  - «паспорт возраста» в конце;
  - анонс следующего периода на карте;
  - музыкальная тема серии.
- Внешние траты — по возможности ноль.
